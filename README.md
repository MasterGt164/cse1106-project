# cse1106-project
## Printing "Hello World"
## Programming language is C
## How to Run
Get #inlcude <stdio.h> to use printf statements. Then make your main int as int main(){}. Inside the brackets write printf and inside the parenthesis use "" to write what you want to print out. then return 0; to end the program. 
## Example
#include <stdio.h>

int main()
{
    
    printf("Hello World");
    
    return 0;
}
